# 产品与任务定义

## 核心用户需求

法国史研究者需要从检索层级混杂、OCR存在噪声的数字档案中，尽可能完整地发现与研究对象有关的材料，并把零散页面恢复成可以理解和引用的历史事件。

## 核心任务

### 任务一：材料分类

输入是一个人物命中及其局部OCR上下文。系统判断：

- 命中是否指向目标人物；
- 材料是正式发言、插话/回应、他人实质提及、提案/报告、表决/名单、目录还是无关内容；
- 材料与当前研究问题属于A、B、C还是D级；
- 是否必须进入人工复核。

### 任务二：事件重建

输入是按页和行编号的连续OCR。系统寻找“最小但语义完整”的事件窗口，至少判断：

- 议题或程序背景；
- Landry发言的起止；
- Landry回应的对象；
- 对Landry的直接回应；
- 可见的处理结果或下一议题起点。

### 任务三：本地档案分件与识读

输入是一批按扫描顺序排列的档案图像。系统先区分数字扫描、物理页和历史文件，判断哪些页属于同一份文件；再显式标注印刷、打字、手写、混合或不确定版式，选择相应视觉转写路线。低置信度、混合版式和不完整转写进入复核队列，不能被静默当成无关材料。

## 输出原则

模型结论不是史料事实。每项输出必须保留原始来源、页码、法文证据、置信等级和复核状态；原文、翻译、摘要与研究解释分层保存。

## 非核心能力

OCR、HTR、翻译和摘要是可替换的下游组件。首版产品的差异化能力是：高召回候选发现、人物/材料语义标注、事件重建和证据追溯。

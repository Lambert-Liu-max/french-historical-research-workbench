# 当前能力边界

## 已验证

- Gallica查询规划、SRU/ContentSearch分页、ARK去重、相邻命中合并、有效缓存与漏检清单；
- 议会材料姓名/发言/名单初筛；
- 7个复杂事件的边界、回应关系、翻译和引用信息端到端整理；
- 私人档案扫描边界、法文转录、翻译、A/B/C分级和复核队列；
- 战后官方议会PDF的批量OCR与专题筛选。
- 本地扫描控制流：只读哈希清单、重叠窗口分件、显式印刷/打字/手稿路由、分批视觉转写、费用与断点记录；

## 已实现但待正式评测

- 通用人物消歧；
- A/B/C/D相关性分类；
- 自适应事件边界优于固定窗口的程度；
- 模型置信度与真实正确率之间的校准。

## 实验性或规划中

- 真实手稿转写准确率的人工金标准评测与多HTR模型横向比较；
- 通用研究问题生成；
- 跨人物、跨馆藏的泛化评测。

Gallica官方接口偶尔返回Cloudflare验证页或暂时性网络错误。程序会把它们记录为待重试异常，不会把“请求失败”解释成“没有史料”；但任何数字检索仍受原始OCR质量和Gallica索引覆盖限制，因而不能承诺数学意义上的零漏检。

本项目不宣称AI替代历史学判断，也不宣称已经穷尽全部相关档案。

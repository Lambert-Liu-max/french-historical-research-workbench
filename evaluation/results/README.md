# Evaluation results

This directory is intentionally empty in the repository template. Benchmark reports
must be generated from saved model responses; no accuracy figure is copied from the
production pipeline or inferred from model agreement.

Only rows explicitly signed off as `gold_status=expert_verified` are included in the
strict leaderboard. Seed, silver and pending rows may be used for dry runs and error
analysis, but their scores must be labelled diagnostic.

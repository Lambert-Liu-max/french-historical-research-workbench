# 真实私人档案案例：从三页手稿到可复核研究记录

> 展示说明：本案例来自研究者已完成的 Landry 私人档案生产运行。为尊重馆藏图像权利，公开仓库不复制原始扫描，只展示必要的档案标识、局部转写、译文和处理审计。研究者可在获得相应授权后，用原图复现视觉识读。

## 任务

输入不是已经整理好的单篇文献，而是一盒连续扫描中的三页手稿。系统需要先判断它们是不是同一份历史文件，再决定使用手稿识读路线，并依据研究问题判断其阅读优先级。

| 项目 | 真实运行结果 |
|---|---|
| 档案盒 | `B-0083105-3` |
| 文件ID | `文件0068` |
| 扫描页 | `276–278`，共3页 |
| 日期证据 | 信笺可见`3 DEC 1952`戳记；是否等同写作日期待核 |
| 类型 | 法国共和国议会（Conseil de la République）信笺上的手写讲话稿 |
| 作者 | 待人工核验；不能仅因材料保存于Landry档案即直接确认 |
| 边界判断 | 三页信笺一致，手写页码连续为1、2、3，第3页末尾存在结束标记 |
| 边界置信度 | high |
| 研究等级 | A |
| 主题 | 法国出生率、人口老龄化、家庭政策、《家庭法典》 |
| 模型调用 | 1次手稿转写＋1次翻译 |
| 该文件估算费用 | 0.0711美元（不含共享边界窗口） |

## 局部法文转写

```text
Du côté du nombre, nous sommes présentement en progrès.
La natalité française, dans la période très récente, s'est
relevée notablement : on n'hésitera pas à en rendre grâce aux
lois salutaires de 1931, 1939 (le Code de famille) et 1942…
```

转写保留原有拼写和换行，不用模型知识补齐不可见文字。三页共形成3,843个法文字符；系统显式保留11处`[无法识别]`和1处`[nombre?]`存疑读法。

## 对应中文译文

> 就数量而言，我们目前正在进步。法国的出生率（natalité française）在最近这一时期显著回升：我们毫不犹豫地要把这归功于1931年、1939年（《家庭法典》）和1942年的有益法律……

完整译文共1,154个中文字符。翻译继承转写中的不确定性，不根据历史背景擅自补写缺字，并列出7项翻译疑难。

## 问题意识驱动的分级

研究问题是：Landry如何把人口、家庭与社会政策思想转化为制度行动？系统将本件判为A级，而不是因为它出现了“Landry”或“population”就机械入选，理由是它把三个层面直接联系起来：

1. 对出生率恢复与人口老龄化的判断；
2. 对1931、1939和1942年家庭立法的因果评价；
3. 对家庭生活条件、国家力量和人口质量的政治论证。

## 为什么仍进入人工复核

模型虽然高置信度确认三页属于同一文件，但第3页手迹较难，存在多处无法可靠识读的语句，作者身份以及日期戳记的性质也尚未人工核验。因此系统保留已经可用的证据，同时将整份文件标记为`needs_review=true`。这体现了产品的核心原则：

```text
可用证据继续进入研究语料
         ＋
局部不确定性进入复核队列
         ≠
模型猜测缺字或整份文件被丢弃
```

## 可审计产物

真实运行保留了源文件SHA-256、分件窗口、边界主判断与复核、逐页转写、连续译文、模型原始响应、token、费用和复核理由。公开版本只展示脱敏后的最小证据，不公开原始绝对路径、API密钥或整盒档案。

本案例证明的是端到端控制流和不确定性治理已经用于真实档案；它不等同于手稿字符准确率评测。后者仍需研究者制作逐字人工金标准。
